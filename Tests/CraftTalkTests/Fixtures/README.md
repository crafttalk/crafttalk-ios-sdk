# Синтетические сертификаты

`synthetic-root-1.der` и `synthetic-root-2.der` созданы исключительно для тестов
через OpenSSL: RSA 2048, SHA-256, self-signed CA, CN `CraftTalk Synthetic Test Root 1/2`,
O `TEST ONLY`. Приватные ключи создавались во временном каталоге и удалены;
в репозитории находятся только публичные DER-сертификаты.

Этап 1 проверяет чтение DER и разделение настроек по хостам. Сертификаты не
устанавливаются в системное доверие и не используются для реальных TLS-соединений.
Их срок действия не участвует в этих проверках; TLS-проверки относятся к этапу 2.

Для этапа 2 `scripts/run-network-tests.py` создаёт отдельные сертификаты перед
каждым запуском: CA для SDK, посторонний CA, системный тестовый CA, intermediate
и несколько leaf. Runtime-сертификаты всегда синтетические. Их публичные DER
и конфигурация сервера временно лежат в игнорируемом `Fixtures/Runtime/`, ключи —
в отдельном временном каталоге вне репозитория. Оба каталога очищаются после
прогона. Системный тестовый CA устанавливается только в одноразовый симулятор,
который затем удаляется. Подробности — в [CI и тестировании](../../../docs/ci-and-testing.md).
