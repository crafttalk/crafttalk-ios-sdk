# Покрытие CraftTalk iOS SDK

Набор проверяет существующий SDK из базы PR №8
(`dc7817665f97dce4e3a157e312e33f3d9f0aa076`). Для клиентов действуют инструкции
по [интеграции](../README.md) и [конфигурации безопасности](security-configuration.md).
Команды и артефакты описаны в [CI и тестировании](ci-and-testing.md),
критерии написания тестов — в [правилах качества](testing.md).

| `CTVisitorTests` | 7 | SHA-256 по независимым векторам с контролируемым входом, Unicode, явный hash, сериализация и валидация вложенного JSON |
| `CTPushRequestTests` | 2 | Сохранение URL-префикса, порта и завершающего slash, метод, Content-Type и JSON |
| `CTChatErrorTests` | 4 | Диагностика без посетителя, пути URL и секретов, callback на главной очереди |

| `CTLegacyTLSIntegrationTests` | 4 | Оценщик SDK на настоящих challenges с подходящим leaf, заменой leaf, неприменимым хостом и отдельной политикой secure |
| `CTNativeNetworkTests` | 23 | Штатная нативная сессия с системным CA. Байты файлов, статусы и обрыв ответа, повтор, GET/POST и редиректы, в том числе POST 307 между хостами с проверкой тела и cookies на обоих запросах. Два TLS-класса передают настоящий challenge штатному оценщику из тестового
URLSession delegate. Тесты нативной сессии дополнительно показывают, что
системный CA работает через сам SDK, а частный CA без конфигурации отклоняется.
Утверждения о подключении secure-политики к нативным callbacks выходят
за пределы этого SPM-набора.

## WebKit на iPhone 16 / iOS 18.6

Точный состав из 33 сценариев задаёт [UI-манифест](../Tests/expected-ui-tests.json).
Ниже указаны результаты, которые тесты проверяют в каждой группе.

| Группа | Наблюдение |
| --- | --- |
| Публичная настройка и push | Явный hash и поля посетителя приходят в JS в обоих режимах. После авторизации в secure меняются атрибуты поля, на сервере виден POST push с ожидаемым UUID и токеном |
| Навигация | Тот же WebView открывает разрешённый документ, в том числе обычную ссылку с `target=_blank`. Реальные внешние ссылки открывают Safari, в том числе из программно созданных open/closed Shadow DOM. Неразрешённый хост в редиректе или автоматическом переходе не получает запрос. Ссылки tel/mailto передаются интерфейсу UIApplication |
| WKDownload | MIME, disposition и атрибут `download`, ссылка за нижней границей, разрешённые редиректы, iframe, GET/POST, одноразовый URL, точные байты и cookies. Закрытие меню удаляет файл и каталог. Подмена страницы выявляется по pageID, журналу и изменённому через XCUITest черновику |
| Отказ и повтор WKDownload | TLS, HTTP, запрещённые направления, обрыв тела, конкурирующий WKDownload, недоступное представление меню. Удерживаемое тело даёт наблюдаемую границу между запросом и его завершением |
| Blob-предпросмотр | Штатный WebKit-мост в обоих режимах открывает синтетический текстовый файл с проверкой байтов. Кнопка «назад» возвращает к изменённому черновику. В legacy можно снова открыть preview или снова показать меню, пока preview видим |
| Жизненный цикл и picker | Повторное открытие экрана, отмена жеста «назад» при загрузке, поворот, обычный фон/возврат и системный выбор синтетического файла с проверкой POST |
| Изоляция и диагностика стенда | Повторный запуск после прерванного сценария убирает его файлы и данные сайта. Ошибка JS очищает снимок и наблюдение восстанавливается. Ошибка чтения файла фигурирует в диагностике |

TLS и перенаправления в WebKit могут происходить до превращения навигации
в WKDownload. Проверки опираются на внешние результаты, включая журнал HTTPS,
и не требуют конкретной доставки внутренних WebKit callbacks на каждом переходе.
Сценарий системного выбора файла подтверждает штатный picker и передачу
байтов локальной странице. Синтетический HTML и test host изолированы от Example.

## Границы покрытия

- **Инициализация и hash.** В базе настройка из Info.plist асинхронна.
  Host ждёт её на публичной очереди SDK. Чтение `CTSalt` известно как
  ограничение базы. Интеграционные ожидания синхронности, успешного
  автоматического hash из `CTSalt` и нового поведения ошибочного Info.plist
  удалены. Векторы алгоритма проверяются отдельно с заданным входом.
  Коллизии ключей `customProperties` исключены из обязательных тестов.
- **Жизненный цикл.** Освобождение связки контроллер/WebView, отмена незавершённой
  загрузки при закрытии экрана и очистка при программном закрытии меню не входят
  в набор. Повторное открытие проверяет навигацию и новый запрос страницы.
  Отмена жеста с открытым legacy-preview исключена. Фон/возврат не моделирует
  выгрузку приложения системой.
- **Blob и legacy.** В базе blob сохраняется непосредственно в tmp и
  открывает preview. Сценарии меню вместо preview, очистки blob-файлов при
  закрытии и общего ограничения конкуренции blob/WKDownload требовали изменений
  SDK. Некорректные сообщения моста и сценарии, закрепляющие известные
  ограничения legacy-доверия, исключены. Положительные проверки остаются на
  корректных синтетических данных.
- **Транспорт и навигация.** Изолированные конструкторы, подменяемый планировщик,
  URLProtocol, инъекция временного каталога и принудительная инвалидизация SDK
  отсутствуют в базе. Их тесты удалены. Нативный набор фиксирует наблюдаемый
  результат обычных запросов; UI-набор отдельно подтверждает HTTPS-отказы и
  редиректы с настоящим WebKit. Специальные сценарии подделки активации,
  автоматической загрузки из iframe, проверки границ имён на обход путей
  и обхода доверия в обязательные наборы не входят. Поддержка ссылки
  `target=_blank` на документ не распространяется на скачивание в новом окне.
- **Платформы.** [Поднабор совместимости](../Tests/ui-compatibility-tests.json)
  предназначен для iPad (A16) / iOS 18.6 и iPhone 15 / iOS 17.4. Набор не
  заявляет покрытие preview-share на iPad. Физические устройства, Firebase/APNs,
  внешний сервер, старые версии iOS, нагрузка и полный аудит безопасности
  требуют отдельных проверок.

Оба полных набора проверяют сводку и идентификаторы в `.xcresult`. Пропуск,
expected failure, повтор или отсутствие обязательного сценария дают ошибку.
Локальный прогон подтверждает выбранные Xcode и runtime. Для результата Actions
нужен запуск самого workflow.
